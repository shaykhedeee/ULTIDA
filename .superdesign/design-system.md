# ULTIDA studio workspace design system

ULTIDA is an interior-design production workspace, not a branded furniture marketplace. Keep its warm paper-and-ink system, real project data, scene-first authority, and accessible professional density.

- Preserve the existing warm canvas, dark ink, restrained brown primary action, and muted gold workflow signal.
- Borrow only the useful catalogue structure from the supplied public reference: a persistent family rail, search, clear filters, compact visual cards, and a details/configure action.
- Never show external brands, product prices, invoices, shopping carts, or copied source labels.
- Cards represent configurable modular templates; each must show family, room suitability, dimensions in millimetres, and production/verification status.
- Dashboard should be a calm command centre: studio greeting, truthful project status, direct tools, and active-project continuation. It must not fabricate provider readiness or data.
- Use 8px spacing rhythm, 6–10px control radius, strong readable sans-serif headings, visible focus states, and mobile-first stacking.
- Keep a single primary action in each card/section. Secondary actions should be outlined or text links.
