# Agent B Studio | Sign In

## Business Context
- **Type/Industry:** SaaS / AI visualization platform for design professionals
- **What they do:** AI-powered render, moodboard, and product visualization generation
- **Target audience:** Interior designers, architects, brands
- **Page goal:** Authenticate returning users into the platform

# Page Layout & Structure

### Hero
Centered, full-viewport dark card (navy background with darker navy border) positioned vertically centered on navy page. Agent B icon (purple/cyan gradient, ~80px) sits above h3 "Welcome back" in white. Subheading "Sign in to your Agent B account" in gray below. Two stacked form fields (Email + Password with label pair) occupy 364px width. Password field includes "Forgot password?" link in purple, right-aligned. Full-width "Sign in" button in purple fills container, contains right-pointing arrow icon + white text. Below form: gray text "Don't have an account?" + purple "Sign Up" link. Card uses rounded corners (medium radius), no outer shadows, sits ~40% down page vertically.

### Header / Navigation
Horizontal static bar, navy background. Left: Agent B logo (icon + wordmark "Agent B" in white). Center: 4 nav links (Designer, Brand, Real Estate, Pricing) in gray text. Right: "Get Started" button in gradient (purple→cyan), pill-shaped, white text. Logo links to `/`. No hamburger.

### Primary CTA / Input
**Sign in button:** full-width, purple background, white text "Sign in", left-aligned arrow icon, pill-shaped corners, sits below password field in form card.

### Email input field
- **Purpose:** Capture user email for authentication
- **Layout:** Label "Email" above; textbox with placeholder "you@example.com", navy background, rounded corners, gray placeholder text

### Password input field
- **Purpose:** Capture user password; optional reveal toggle
- **Layout:** Label "Password" above with "Forgot password?" link (purple) right-aligned; textbox with dots placeholder, eye icon toggle on right side, navy background, rounded corners

### Sign Up link
- **Purpose:** Redirect new users to account creation
- **Layout:** Gray text "Don't have an account?" + purple "Sign Up" link; positioned below Sign in button, center-aligned

### Footer
- **Purpose:** Legal + company links + copyright
- **Layout:** 4 links (Privacy Policy, Terms of Service, Refund & Cancellation, Contact Us) left side in gray; copyright text "© 2026 Agent B Studio. All rights reserved." right side in gray; navy background, static

**Notable patterns:** Hero card is centered container on full-viewport navy page; form uses stacked single-column layout; all interactive elements (inputs, buttons, links) use rounded corners with purple accent for primary actions and links; gray text reserved for labels and secondary information; green chat widget (WhatsApp) floats bottom-right corner outside form card.
