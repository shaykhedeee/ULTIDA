# ULTIDA elevation worker

Optional Python envelope exporter; the active TypeScript scene/drawing pipeline remains the manufacturing authority. Run `PYTHONPATH=workers/elevation python -m pytest workers/elevation/tests -q` after installing `requirements.txt` and pytest.

Projects wall-local module envelopes from saved dimensions, preserves mounting height and rejects out-of-wall geometry. It does not infer shutters, fittings or joinery from an envelope. SVG labels are escaped UTF-8. Arbitrarily rotated modules and exact drawing scale/pagination require the main drawing pipeline; this worker does not certify fabrication or CNC operations.
